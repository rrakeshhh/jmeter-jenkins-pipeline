\# JMeter CI/CD Pipeline with Jenkins \& Grafana



This project demonstrates how to integrate \*\*Apache JMeter\*\* with \*\*Jenkins CI/CD\*\* and monitor live performance metrics using \*\*InfluxDB \& Grafana\*\*.
